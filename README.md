# AI-Powered Job Search Assistant

Een platform dat de job search cyclus automatiseert en optimaliseert. Het systeem analyseert je CV, zoekt passende vacatures, en genereert gepersonaliseerde cover letters waar nodig.

## Project

### Waarom dit project?

**Persoonlijke ervaring:**
Tijdens mijn zoektocht naar een stageplek merkte ik verschillende frustraties:

- Mijn CV was niet altijd optimaal afgestemd op specifieke vacatures
- Interessante jobs lieten ik soms links liggen wanneer ze om een cover letter vroegen
- Het schrijven van cover letters voelt als een verplicht nummer zonder echte toegevoegde waarde
- Het is moeilijk om alle relevante vacatures bij te houden over verschillende platforms

**De oplossing:**
Een geautomatiseerd systeem dat:

1. **CV Optimalisatie** - AI analyseert je CV en geeft concrete verbeteringsuggesties
2. **Job Matching** - Scant job boards en matcht vacatures met jouw profiel, ook die je misschien over het hoofd zou zien
3. **Cover Letter Generator** - Genereert automatisch gepersonaliseerde cover letters per bedrijf, zodat dit geen blokkade meer is om te solliciteren

### Hoe kom ik erbij?

Als graduating student sta ik voor dezelfde uitdaging: het vinden van mijn eerste job na mijn studies. Mocht dit proces even tijdrovend en frustrerend zijn als het vinden van mijn stage, dan zou dit systeem mij (en andere studenten) enorm helpen.
Daarnaast heb ik interesse in internationale opportunities(zoals Australië), wat betekent dat ik jobs moet monitoren over meerdere landen en platforms.

### Waarom innovatief?

- **Combinatie van technologieën:** AI (analyse & content generatie) + automation (scraping & workflows) + modern web development
- **Praktische toepassing:** Niet enkel een theoretische exercise, maar een bruikbaar product
- **Nieuwe tech stack voor mij:** Python development, AI API's, n8n - allemaal nieuw bovenop mijn C#/.NET ervaring
- **Relevant probleem:** Veel studenten/starters worstelen met hetzelfde probleem

### Core Features

- CV Analysis & Optimization
- Automated Job Scraping & Matching
- Cover Letter Generation
- Application Dashboard

### Tech Stack

- **Backend:** Python

- **Database:** PostgreSQL
